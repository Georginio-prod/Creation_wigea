## 📌 Présentation

Projet du cours **IHM (Interface Homme-Machine)**, novembre 2023 : un site de **boutique de mode** avec catalogue, fiche produit, FAQ, pages de connexion et d'inscription.
Le site est basé sur le template gratuit **Tooplate WIGEA Fashion**, adapté et personnalisé
(textes, images, pages) pour l'exercice.

## 📄 Pages

- `index.html`
- `products.html`
- `product-detail.html`
- `about.html`
- `faq.html`
- `contact.html`
- `sign-in.html`
- `sign-up.html`

## 📁 Structure

`index.html` et pages HTML à la racine, `css/`, `js/`, `fonts/`, `images/`.

## 🚀 Lancement

Aucune installation : cloner et ouvrir `index.html` dans un navigateur.

```bash
git clone https://github.com/Georginio-prod/Creation_wigea.git
```

## 🌐 Déploiement

Déployé sur **Vercel** en site statique : <https://wigea-fashion.vercel.app>.
